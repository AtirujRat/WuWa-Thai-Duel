# อัปเดตกฎตามเฟส (20 กันยายน 2026)

ห้องใหม่ทั้งโหมดเพื่อนและบอทใช้กฎพื้นฐานตามคู่มือทางการ: เลือกก่อน/หลัง มัลลิแกน จั่วตามเทิร์น คอนแชร์โต อัปเลเวล เปิดการ์ดพร้อมกัน คอมโบ และรีเฟรชเด็ค อ่านรายละเอียดและขอบเขตเอฟเฟกต์ใน RULES-TH.md

ห้องเดิมคงระบบเดิมไว้ ข้อความเกี่ยวกับโต๊ะจำลองและบอทกติกาย่อด้านล่างเป็นคำอธิบายของห้องรุ่นเดิม

# WuWa Thai Duel — เดโมบนเครื่อง

ดับเบิลคลิก **START-DEMO.cmd** แล้วเปิด http://localhost:4174 หากเบราว์เซอร์เปิดเร็วกว่าตัวเซิร์ฟเวอร์ ให้รีเฟรชอีกครั้ง ต้องมี Node.js 22 ขึ้นไป (เครื่องที่สร้างเดโมมีแล้ว) ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## สิ่งที่ลองได้

- ค้นหาชื่อไทย อังกฤษ ญี่ปุ่น รหัสการ์ด และข้อความความสามารถ กรองชุด ประเภท และตัวละคร
- อ่านคำแปลไทยฉบับร่างครบ 123 รหัส พร้อมต้นฉบับญี่ปุ่น และเลือกดูภาพเวอร์ชันต่าง ๆ รวม 194 รายการ
- จัดเด็ค ตรวจจำนวนและทีมเบื้องต้น บันทึก โหลด นำเข้า/ส่งออก JSON และใช้เด็คฝึก SD01 หรือ SD02
- สร้างห้อง 1 ต่อ 1 แจกไพ่ สับเด็ค เปลี่ยนมือเริ่มต้น วางไพ่คว่ำเปิดพร้อมกัน ย้ายเขตการ์ด เปลี่ยนผู้นำ/เลเวล ปรับไลฟ์ ส่งเทิร์น และยอมแพ้

## เล่นกับเพื่อน

1. เปิดเดโม ไปที่ “เล่นกับเพื่อน” ตั้งชื่อและเลือกเด็คฝึก หรือเลือกเด็คที่บันทึกไว้
2. สร้างห้องแล้วส่งรหัสห้องให้เพื่อน
3. เครื่องเดียว: ใช้อีกเบราว์เซอร์หรือหน้าต่างส่วนตัวเพื่อทดสอบผู้เล่นคนที่สอง
4. คนละเครื่องบน Wi-Fi เดียวกัน: ให้เพื่อนเปิดที่อยู่ **LAN** ที่แสดงในหน้าต่างเซิร์ฟเวอร์ เช่น http://192.168.x.x:4174 แล้วใส่รหัสห้อง หาก Windows ขอสิทธิ์เครือข่าย ให้เลือกเครือข่ายส่วนตัวที่ใช้เล่น
5. เลือกเปลี่ยนมือเริ่มต้นได้คนละครั้ง แล้วทั้งสองฝ่ายกด “พร้อมเล่น”
6. เมื่อแต่ละฝ่ายเลือก “วางคว่ำ” ระบบเปิดทั้งสองใบพร้อมกัน จากนั้นผู้เล่นคิดเอฟเฟกต์ ค่าใช้ และความเสียหายเองตามการ์ด

คลิกการ์ดในมือหรือเขตของตนเองเพื่อย้ายเขต คลิกภาพเพื่ออ่านคำแปล ปุ่ม “เปิดมือให้คู่เล่นดู” ใช้เมื่อเอฟเฟกต์กำหนดให้แสดงมือ และปิดการแสดงได้

**เดโมเป็นโต๊ะจำลอง ไม่ได้บังคับกฎหรือตัดสินเอฟเฟกต์อัตโนมัติ** การตรวจเด็คเป็นขั้นพื้นฐานเท่านั้น เด็คฝึกไม่ได้อ้างว่าเป็นรายการจำนวนตรงตามกล่องจริง การเล่นนอกเครือข่ายบ้านยังไม่ได้ตั้งค่า และยังไม่มีการเผยแพร่เว็บไซต์

## ข้อมูลการ์ด

รวบรวมจาก https://wwcg.ucp-jp.com/jp และ API สาธารณะของ UCP วันที่ 19 กันยายน 2026 ฐานข้อมูลภาษาญี่ปุ่นคืน 194 รายการ รวมรหัสซ้ำได้ 123 รหัส: SD01 23 / SD02 23 / BP01 77

นี่คือครบรายการที่ API คืนมา ณ วันที่รวบรวม **ไม่ใช่การยืนยันว่าครบการ์ดทุกใบที่เคยจำหน่ายหรือโปรโมทุกใบ** ลายพิเศษใช้รหัสเดียวกันจึงไม่เพิ่มจำนวนรหัสในเด็ค ภาพบันทึกในเครื่องและแสดงต้นฉบับโดยไม่แก้ไข ภาพและข้อมูลเป็นของ KURO GAMES / UCP

คำแปลไทยไม่เป็นทางการ เป็นฉบับร่างเพื่อทดสอบ ยังต้องให้ผู้เล่น/ผู้ตัดสินตรวจทานศัพท์และเงื่อนไขก่อนใช้แข่งขัน มีข้อความต้นฉบับและลิงก์ข้อมูลแต่ละใบในรายละเอียด เก็บขอบเขตไว้ใน public/catalog-meta.json

อ้างอิงกฎจัดเด็คเบื้องต้น: https://w.atwiki.jp/wuwatcgwiki/pages/129.html

## การบันทึก

เด็คและสถานะห้องเก็บที่ data/demo-v2.json ฝั่งเซิร์ฟเวอร์ เซิร์ฟเวอร์ไม่ส่งไพ่ลับหรือโทเคนคู่แข่งไปยังเบราว์เซอร์ บัญชีเดโมใช้คุกกี้ของแต่ละเบราว์เซอร์ การกลับเข้าที่นั่งเดิมหลังรีเฟรชใช้ข้อมูลในแท็บเดิม หากปิดแท็บหรือเปลี่ยนเครื่องอาจต้องสร้างห้องใหม่ ให้ส่งออกเด็คไว้ก่อนล้างคุกกี้

ปิดหน้าต่างเซิร์ฟเวอร์เพื่อหยุดใช้งาน สำรองโฟลเดอร์ data หากต้องการเก็บเด็คและห้อง อย่าแชร์ไฟล์ data/demo-v2.json เพราะมีข้อมูลไพ่ลับและสิทธิ์ห้อง

## พัฒนาต่อ

ไฟล์เว็บอยู่ใน public/ ตัวเซิร์ฟเวอร์คือ server.mjs และการทำงานโต๊ะจำลองอยู่ใน engine.mjs ทดสอบด้วย `node --test tests/*.test.mjs` ก่อนโฮสต์จริงควรเพิ่มระบบบัญชี การเชื่อมต่อที่เข้ารหัส และตรวจทานกฎ/คำแปลให้ครบ

## อัปเดต: เล่นกับบอท

ไปที่ “เล่นเกม” เลือกเด็คของคุณ แล้วกด “เริ่มเล่นกับบอท” เลือกบอทระดับง่าย (สุ่ม) หรือปกติ (เลือกตามค่าการ์ด) และเด็คบอท SD01/SD02 ได้ เปลี่ยนมือก่อนกดพร้อมเล่น จากนั้นเลือกการ์ดและกดรอบถัดไป

โหมดนี้ใช้กติกาฝึกแบบย่อ: แดงชนะเขียว เขียวชนะน้ำเงิน น้ำเงินชนะแดง สีเดียวกันใช้ความเร็ว ผู้ชนะทำความเสียหายตามการ์ดอย่างน้อย 1 เริ่มแต่ละรอบได้พลังงาน 1 สะสมสูงสุด 3 ตั้งแต่รอบ 2 จั่ว 1 ใบ ค่าใช้หักจากพลังงาน ไม่ใช้ข้อความเอฟเฟกต์ สกิลตัวละคร เลเวลอัป หรือคอมโบ จบที่ไลฟ์ 0 หรือครบ 40 รอบแล้วเทียบไลฟ์ ไม่ใช่กฎแข่งขันเต็มรูปแบบ

บอทเลือกการ์ดล่วงหน้าก่อนผู้เล่น และไม่อ่านไพ่บนมือของผู้เล่น เซิร์ฟเวอร์เก็บไพ่บอทเป็นความลับจนเปิดพร้อมกัน

ชื่อการ์ดแสดงเป็นภาษาอังกฤษ ส่วนเมนูและคำแปลความสามารถเป็นภาษาไทย ชื่อแอ็กชันภาษาอังกฤษเป็นชื่อแปลสำหรับเดโม ไม่ได้ยืนยันว่าเป็นชื่อฉบับภาษาอังกฤษทางการ ยังค้นด้วยชื่อไทยเดิมได้
